Drift

The approved values are frozen in this script; the live column is read back out of src/scss/globels/_tokens.scss on every run. A token can drift without moving a single contrast ratio — one ground swapped for another of the same luminance, a hairline retuned — so this is gated separately from the arithmetic and fails the build on its own.

No drift

Every gated token in _tokens.scss matches the value signed off on 1 September 2026.

The arithmetic

Threshold is selected by kind: body text 4.5:1, large text and non-text elements that carry meaning 3:1, decorative fills nothing. A failure both palettes share is inherited from the guide and is not ours to fix; one only we have, we introduced.

Nothing introduced

Every check the guide passes, the live palette also passes. The brand tone clears the 4.5:1 reading threshold on all three light grounds, so it substitutes directly for the guide's green at every call site — no darker reading tone has to be invented.

1 inherited failure(s) — report, do not fix

Present in the guide as drawn and therefore identical across every group site: Outline button border. Fixing one on a single site forks the group design system. Raise it with the guide's author as a change to the shared layer.
